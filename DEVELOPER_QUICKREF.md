# Developer Quick Reference

> Quick reference card for developers contributing to the Gatewayz Python SDK

## Setup (5 minutes)

```bash
# Clone and navigate
cd /path/to/sdks/python

# Create virtual environment
python -m venv venv
source venv/bin/activate  # Linux/Mac
# OR: venv\Scripts\activate  # Windows

# Install in dev mode
pip install -e ".[dev]"

# Verify
python test_install.py
```

## Key Commands

### Development
```bash
# Install
pip install -e ".[dev]"

# Test installation
python test_install.py

# Format code
black . && isort .

# Lint
ruff check --fix .

# Type check
mypy .
```

### Testing
```bash
# Run tests
pytest

# With coverage
pytest --cov=gatewayz

# Specific test
pytest tests/test_auth.py -v
```

### Making Changes
```bash
# Create branch
git checkout -b feat/my-feature

# Make changes (only edit safe files!)

# Test
python test_install.py

# Format
black . && isort .

# Commit
git commit -m "feat: add new examples"

# Push
git push origin feat/my-feature
```

## Architecture at a Glance

```
User Code
    ↓
GatewayzApi(token, base_url)
    ↓
Module Clients (chat, authentication, models, etc.)
    ↓
RawClient (HTTP layer)
    ↓
ClientWrapper (auth, headers)
    ↓
httpx → API
```

## Common Tasks

### Add an Example
```python
# Edit examples.py
def new_feature_example():
    """Example of new feature."""
    client = GatewayzApi(
        token="YOUR_TOKEN",
        base_url="https://api.gatewayz.ai"
    )
    result = client.models.get_models(limit=5)
    print(result)
```

### Test Locally
```python

client = GatewayzApi(
    token="your-token",
    base_url="https://api.gatewayz.ai"
)

health = client.health_check_health_get()

```

## Client Usage Patterns

```python
from gatewayz import GatewayzApi
from gatewayz.types import Message

client = GatewayzApi(token="...", base_url="...")

# Health checks (no auth)
client.health_check_health_get()
client.ping_ping_get()

# Catalog
client.models.get_models(limit=10)
client.providers.get_providers()

# Authentication module
client.authentication.get_user_balance()
client.authentication.get_user_profile()

# Chat
client.chat.chat_completions(
    model="gpt-4",
    messages=[Message(role="user", content="Hi")]
)
```

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Import error | `pip uninstall gatewayz -y && pip install -e .` |
| Type conflict | Don't run Python from SDK root directory |
| Format failing | Update black: `pip install --upgrade black` |
| Tests failing | Check you're in venv: `which python` |

3. Test regenerated SDK
4. Commit both spec and code
